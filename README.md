## สิ่งที่ต้องเตรียมก่อนรันโปรเจกต์

- ติดตั้ง Docker Desktop และเปิดใช้งานอยู่
- Port `8000` ต้องว่างอยู่

### Clone Repository

```bash
git clone <repository_url>
cd <repository_url>
```


## วิธีรันโปรเจค

### 1. เริ่มต้น container
```bash
docker compose up --build -d
```

### 2. โหลดข้อมูลตัวอย่าง
```bash
docker compose exec django python manage.py seed_rooms
```

### 3. สร้าง superuser
```bash
docker compose exec django python manage.py createsuperuser
```

### 4.  **เข้าใช้งานระบบ**
* **Django API (Browsing):** `http://localhost:8000`
* **pgAdmin (Database Manager):** `http://localhost:5050`
